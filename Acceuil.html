Dossier Classifié : Biohazard

Présentation du Projet

Ce site web a été conçu dans le cadre du Mini-Projet Web BTS CIEL (Session 2026) du Lycée Les Lombards. Il documente l'historique de la célèbre franchise de survival-horror développée par Capcom.


  • Objectif : Archiver les menaces biologiques et répertorier les survivants.
  • Technologies : HTML5, CSS3 et JavaScript pur (sans IA superflue).
  • Structure : Site multi-pages interconnecté via un menu de navigation commun[cite: 1].
